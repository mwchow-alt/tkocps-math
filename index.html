☁️ Google Apps Script (GAS) 後端設定

步驟說明：將您的 Google Sheet 試算表變成免費的學生資料庫！

  1. 建立新的 Google 試算表，工作表名稱改為「紀錄」。
  2. 點選【擴充功能】➔【Apps Script】，清空後貼上以下程式碼：
function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.tryLock(10000);
  try {
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getSheetByName("紀錄") || ss.insertSheet("紀錄");
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["時間戳記", "學號", "姓名", "動作", "得分", "備註"]);
    }
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      data.timestamp || new Date().toLocaleString(),
      data.studentId || "",
      data.studentName || "",
      data.action || "",
      data.score !== undefined ? data.score : "",
      data.note || ""
    ]);
    return ContentService.createTextOutput(JSON.stringify({status:"success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({status:"error",message:err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  } finally {
    lock.releaseLock();
  }
}
  1. 點選【部署】➔【新部署】➔ 選擇「網頁應用程式 (Web app)」。
  2. 關鍵：「誰可以存取」選擇「任何人 (Anyone)」！
